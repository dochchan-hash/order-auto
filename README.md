# order-auto · 아파트 한눈에

브라우저에서 단지명 검색 후 공급·전용면적(평/m² 전환), 평형·타입, 사용승인일, 최근 매매 실거래를 조회합니다. 평형 카드 위의 평/m² 버튼으로 면적 표시 단위를 선택하며, 타입명과 선택한 평형은 유지됩니다.

## 실제 연결 수정

- 기존 직접 API 호출에는 공개 페이지에서 발급하는 익명 요청 정보와 웹 요청 헤더가 없어 429가 반환됐습니다. 공개 페이지의 새 익명 세션을 사용하며 사용자 로그인·브라우저 쿠키·계정 자격증명은 사용하지 않습니다.
- Workers가 지원하지 않는 `redirect: error`가 웹 서버에서 요청 자체를 실패시켰습니다. `manual`로 변경하고 정상 상태만 허용합니다.
- 검색 경로와 단지·평형 필드 이름을 실제 응답에 맞췄습니다. 미구현이었던 매매/시세 API를 연결했습니다.
- 금액은 원천의 원 단위를 그대로 사용합니다. 취소 거래·미래 계약은 표시에서 제외합니다.

## 사용

- 최근 매매 기본 6개월, 3/6/12개월 선택. 한국 날짜로 시작일·종료일 포함.
- 최근 거래가 없으면 `최근 매매 실거래 없음` 아래 기관 시세·기준일을 표시합니다.
- 기관 시세도 없으면 `시세 정보 없음`. 연결 실패는 별도의 오류이며 거래 없음으로 바꾸지 않습니다.
- 평형명은 네이버의 공급면적 기준 명칭입니다. A/B 타입을 임의로 추정하지 않습니다.
- 검색 후 `링크 복사`로 해당 단지의 URL을 복사할 수 있습니다.
- `화면 예시 보기`는 명시적인 가상 예시이며 실제 자료 대신 자동 표시하지 않습니다.

## 레몬하우스 차량 이동시간

- 실제 서울·경기 아파트를 고른 뒤 하단 `레몬하우스 지점별 이동시간` 스위치를 켭니다. 기본은 꺼짐이며 꺼진 상태에서는 경로를 요청하지 않습니다.
- 서울본점·목동점·마포직영점·은평점·광교직영점·동탄점·남양주점·일산점 8개 지점 → 해당 아파트 방향입니다. 네이버 검색·플레이스의 지점명·주소·WGS84 좌표를 대조했습니다(2026-10-19). 각 지점명은 네이버 지도 등록 정보로 연결됩니다.
- 네이버 지도의 추천 자동차 경로를 사용하며 시간·거리·조회 시각과 같은 경로의 지도 링크를 제공합니다. 직선거리 추정값을 표시하지 않습니다.
- 인천은 사용자 지정에 따라 제외합니다. 주택·숙박·카페·화장품점 등 동명 업체와 지점 여부가 확인되지 않은 업체는 목록에 포함하지 않습니다. 지점 운영 정보는 연결된 네이버 플레이스에서 확인하세요.
- 지점별 실패를 구분하고 성공한 자료만 3분간 재사용합니다. 시간은 조회 당시 교통상황 기준이며 차량 진입구와 실제 출발 시각에 따라 달라질 수 있습니다.
- `/api/travel?id=<단지번호>`는 서버가 지점과 아파트 위치를 검증합니다. 수도권 밖 또는 잘못된 단지번호는 400으로 거절합니다.
