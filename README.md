# 아파트 한눈에

팀원이 웹브라우저에서 사용하는 아파트 면적·타입·준공년도·매매가격 조회 프로그램입니다.

## 현재 상태 — 개발 중, 실사용 미검증

- 화면과 가격 표시 규칙, 단위 변환, API 입력 검증, 조회 실패 구분을 구현했습니다.
- 네이버의 실제 검색/단지/평형 요청에서 HTTP 429 TOO_MANY_REQUESTS를 확인했습니다.
- 성공한 단지 응답을 확보하지 못했으므로 `lib/naver.ts`의 단지 필드 매핑은 검증되지 않았습니다.
- 실제 매매/시세 연동은 미완료입니다. `/api/prices`는 이를 503 SOURCE_UNVERIFIED로 명시합니다. 이 응답을 거래 없음으로 취급하지 않습니다.
- `화면 예시 보기`는 가상 단지/가상 가격을 명확히 표시하는 화면 검토 기능입니다. 실제 데이터 실패 시 자동 전환하지 않습니다.
- 개인 검토용 배포와 팀 실사용 공개를 구분합니다. 네이버 데이터의 정상 조회와 가격 정확도가 확인되기 전에는 팀 공유용으로 완료하지 않습니다.

## 사용 규칙

- 최근 매매: 한국 날짜 기준 기본 6개월, 3/6/12개월 선택.
- 기간 시작일과 종료일을 포함하고 취소·미래 거래를 제외합니다.
- 최근 거래가 없으면 `최근 매매 실거래 없음`, 바로 아래에 기관 시세·기준일을 표시합니다.
- 시세도 없으면 `시세 정보 없음`, 조회 실패는 별도의 실패 상태입니다.
- 공급/전용면적을 구분하고 1평=3.305785㎡로 환산합니다.
- A/B 타입에 거래를 연결할 때는 원천 데이터의 타입 식별 근거가 필요합니다. 같은 전용면적이면 타입을 임의로 추정하지 않아야 합니다.
- 매물 호가는 기관 시세로 표시하지 않습니다.

## 로컬 실행 / 검사

Node.js 22.13 이상이 필요합니다. 설치된 의존성을 사용합니다.

```text
node scripts/run-framework.mjs dev
node node_modules/typescript/bin/tsc --noEmit
node --experimental-transform-types --test tests/domain.test.mjs
```

로컬 주소는 http://127.0.0.1:5173 입니다. 다른 컴퓨터에 공유하는 주소는 별도 호스팅 배포 후 발급되는 HTTPS URL입니다.

배포는 Sites 스킬의 소스 동기화/아카이브/배포 흐름을 사용합니다. `.openai/hosting.json`의 기존 project_id를 보존하고 사이트를 중복 생성하지 마세요. 비밀 키와 저장소 자격 증명은 파일에 저장하지 않습니다.

## 검증 증거

- `tests/domain.test.mjs`: 기간 경계·취소/미래 거래 제외, 원 단위 금액, 평 환산, 오류와 빈 목록 구분, 성공 응답 캐시, 429 재요청 제한.
- `outputs/screenshots/`: 브라우저 화면 캡처. 예시 화면은 실제 실거래/시세 검증을 증명하지 않습니다.
- 네이버 실제 응답은 별도 API → 데이터 경계의 성공 증거가 확보되어야 합니다.

## 알려진 차단 요인 / 다음 작업

1. 네이버의 허용된 안정적인 데이터 공급 경로를 확보하고 성공 응답으로 필드 매핑을 검증합니다.
2. 원천의 매매금액 단위와 취소 여부·계약일·면적/타입 연결 기준을 검증한 뒤 `/api/prices`를 연결합니다.
3. 네이버를 사용할 수 없으면 사용자에게 확인한 공식 대체 자료의 이용권한/키로 연동합니다.
4. 배포 서버에서 실단지를 검색하고, 거래 있음/없음/시세 없음/조회 실패를 각각 확인합니다.
5. 각자의 PC에서 공유 링크로 접속하는 것을 검증한 후 팀 실사용 공개 및 완료를 선언합니다.
